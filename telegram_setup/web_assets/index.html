Что разрешить агенту?

Выбор сохраняется отдельно от входа в аккаунт. Наличие возможности не означает поручение её использовать.

Загрузятся закреплённые зависимости проекта. Текущий Telegram и системный Python сохраняются.

Подключите личный Telegram

Используйте аккаунт, в который уже вошли на телефоне.

Ключи вашего приложения

Откройте my.telegram.org/apps → API development tools. Пример названия: Personal Assistant; платформа Desktop.

Введите только здесь, в локальном мастере. В чат агенту ключи не нужны.

Ключи приложения уже сохранены. Повторно вводить их не нужно.

Отсканируйте в Telegram

На телефоне: Настройки → Устройства → Подключить устройство.

Истёкший QR обновится сам. Обычная камера телефона для этого входа не подходит.

✓ Вход сохранён. Можно проверить MCP.

Убедимся, что всё работает

Проверка запустит MCP и прочитает служебную информацию о вашем аккаунте. Переписка и сообщения в этой проверке не отправляются.

После входа нажмите кнопку ниже.
