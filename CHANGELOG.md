# Изменения

## 25.10.2026

- Локальный браузерный мастер: явный выбор возможностей, frozen bootstrap, вход по обновляемому QR или телефону/коду, скрытый ввод 2FA и настоящий MCP status. Loopback, временный доступ страницы, Origin/Host, no-store/CSP и pipes без вывода секретов. Добавлены исходный Mac launcher и генератор Linux-ярлыка; системные prerequisites подготавливаются отдельно.
- Исправлена передача выбранной приватной директории, managed backend и локального proxy через subprocess SDK в MCP-клиенте и reader gateway. Скрытый Terminal-ввод больше не блокирует Telegram event loop.
- 115 тестов macOS/Linux и отдельная живая приёмка Linux reader: ограниченное чтение двумя SDK-клиентами, запреты записи/чужого чата, отзыв и restart/checkpoint. Настоящий dot-плагин, внешний маршрут и живой GUI-login пока не считаются проверенными.
- Reader gateway для прямых подключений dot и других агентов: шесть MCP tools для статуса, диалогов, контактов, истории, поиска и недавних сообщений. Произвольная передача команд upstream и запись не открываются.
- Отдельные bearer-токены, отзыв/срок действия, разрешённые чаты и контакты, отдельный выбор всех чатов/контактов и телефонных полей. Смена прав проверяется до каждой операции, включая ожидающие запросы.
- MCP Streamable HTTP на loopback с аутентификацией каждого запроса, ограничением Origin/Host и размера тела; stdio-профиль для Secure MCP Tunnel. Публичный незащищённый listener не добавлен.
- `read_dialog_page`: ограниченные страницы метаданных с курсором и архивом, без загрузки всей истории. Инкрементальные сообщения продолжают использовать `read_history_page` и checkpoint.
- Linux persistent backend, managed relay без запуска конкурирующего процесса, выключенные systemd units с backoff и staging без авторизации/копирования сессии.
- Синтетические проверки реального HTTP и stdio MCP, двух клиентов, областей доступа, отзыва, запрета записи, restart/checkpoint и FloodWait. Живой аккаунт Linux и вызов через dot проверяются отдельно; macOS-установка сохраняется.
- Инструкция Linux, примеры Codex/Claude и пустой безопасный реестр агентов.

## 23.10.2026

- Один локальный backend Telegram и отдельные stdio MCP-сессии для нескольких чатов; автоматическое завершение после отключения всех клиентов и завершения инвентаризации.
- `mcp_client.py`: проверка существующего подключения, список/схема tools и вызов с параметрами из JSON без отдельной авторизации.
- `read_history_page`: ограниченные страницы истории с курсором и верхней ID-границей, без скачивания вложений.
- `read_owned_inventory`: группы/каналы с признаком владельца, архив, мигрировавшие группы и собственные боты; продолжение сканирования и соблюдение FloodWait.
- Инструкция обновления общей установки, образец передачи другим агентам и проверка переноса заметок до удаления исходников.
- Conversation Guard сохраняется в режиме локального snapshot/draft: реальные чтения/утверждения/отправки и обещание OS-изоляции не добавлены.
- Guard 0.2.0 отклоняет прежние live-политики. Старый credentialed upstream и production dispatch выключены; `--require-isolation` отказывает до загрузки состояния. Независимый обзор Claude ещё не завершён.
- Изменение или потеря файла разрешений блокирует новые вызовы уже работающего backend до перезапуска. Незавершённая инвентаризация сохраняет процесс между клиентами, чтобы не терять курсор во время FloodWait.

## 22.10.2026

- Явный выбор возможностей установки и их хранение отдельно от авторизации.
- Независимые просмотр/скачивание/отправка вложений, транскрипция с выбором способа и запретом скрытой смены провайдера.
- Offline MCP-матрица прав и синтетические тесты, без личных аккаунтов.
