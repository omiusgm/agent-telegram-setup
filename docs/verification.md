# Что проверено

Дата: 22.10.2026. Платформа: macOS 27.0, Apple Silicon. Это результат конкретной проверки, не обещание работы любой сети или любой будущей версии.

## Рабочая техническая основа

Ранее в изолированной личной установке прошли вход по QR, ветка 2FA, сохранение авторизованной SQLite-сессии и read-only MCP-проверка чтения диалогов. Позднее после временных сетевых сбоев штатный сервер снова прошёл проверку соединения с существующей сессией. Личные ключи, аккаунт, переписка и результаты частных задач в этот репозиторий не переносились.

Публичный пример использует те же Telethon, pinned upstream и подход к конфигурации/блокировке. Интерфейс упрощён до Terminal; браузерный ввод пароля здесь не реализован. Запуск не прогревает всю историю диалогов автоматически: чтение происходит по запросу MCP.

## Проверки публичного пакета

- Чистое скачивание upstream по закреплённому commit и установка отдельной `.venv` через frozen lockfile: Python 3.11.16, Telethon 1.45.0, MCP SDK 1.30.0.
- 23 unit tests: прежние проверки приватного хранения, identity, блокировки и QR, а также явный выбор прав при установке, сохранение без изменения сессии, отказ при ошибочных настройках, отмена выбора, повторная установка без повторного вопроса, совместимость старых профилей и запрет подмены способа расшифровки.
- 13 настоящих offline MCP initialize/list_tools: базовое чтение — 59 tools; чтение со скачиванием — 61; набор `reader` — 65; `assistant` — 73; все перечисленные возможности — 97. Каждая дополнительная группа проверена отдельно. Числа относятся к закреплённой версии; администрирование аккаунта и групп не включается.
- Прямой вызов не выбранного `download_media` отклоняется сервером. Подмена выбранного Telegram-распознавания на Groq отклоняется до обращения к провайдеру. Отправок и сетевых обращений к аккаунтам в этих проверках нет.
- Offline-сервер использует только синтетический API ID, нулевой тестовый Hash и временный каталог. Интернет-соединения блокируются; настоящий вход/отправка в этих тестах отсутствуют.
- Проверка публичного списка файлов и локальных Markdown-ссылок: `python scripts/check_public.py`.

Live-команда новой установки клиента проверяет чтение отдельно после его собственного входа. Не копируйте рабочую сессию с другого компьютера ради «зелёного теста».
