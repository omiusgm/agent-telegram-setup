# Отправка текста и файлов

Отправка текста и файлов выбирается при установке отдельно от чтения и скачивания. Полный список, расшифровка и изменение настроек описаны в [выборе прав](permissions.md).

| Возможность | Дополнительные tools |
|---|---|
| `send-text` | `send_message`, `reply_to_message` |
| `send-files` | `send_file`, `send_album`, `send_voice`, `upload_file`, `send_sticker`, `send_gif` |

Эти пункты независимы: отправка файла не требует разрешения писать обычные текстовые сообщения. Выбранные возможности позволяют выполнять соответствующие поручения владельца; они не являются задачей что-либо отправить прямо сейчас.

Чтобы изменить права, не меняя авторизацию:

```bash
.venv/bin/python -m telegram_setup.permissions
.venv/bin/python -m telegram_setup.permissions --show
```

Перезапустите свой сервер и проверьте list_tools. Не создавайте второй процесс с той же сессией. Дополнительное ограничение tools на стороне клиента может сужать выбранный набор; фактическую доступность проверяйте отдельно. Старые три профиля через `AGENT_TELEGRAM_ACCESS` остаются совместимым вариантом для установок без нового файла выбора.

Файловый корень этого примера — `.local/files/`. Подготовьте конкретный согласованный файл там, вызовите send_file по его реальной схеме и укажите согласованный чат. Ограничения размера/форматов, права аккаунта и проверки upstream сохраняются. Путь вне разрешённого корня может быть отклонён. Не меняйте корень на весь домашний каталог ради одного файла.

Если пользователь запросил выдачу файлов и инструмент доступен, используйте MCP вместо переноса мышкой. «Избранное» (`me`, если поддерживается схемой инструмента) подходит, когда пользователь выбрал это назначение или оно уже согласовано. Если получатель неизвестен — уточните его, не подставляйте случайный последний чат.

После отправки проверьте ответ Telegram и, когда возможно, прочитайте обратно сообщение/метаданные отправленного документа в том же чате. Запущенный upload или локальный файл не доказывает доставку. Массовая рассылка, передача приватного архива, другой получатель и изменение доступа требуют отдельной задачи.
